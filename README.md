# ProcureMind

ProcureMind is an interactive procurement review prototype. It challenges procurement decisions before money moves by reconstructing evidence across the purchase story.

## Demo highlights

- **Challenge This Purchase:** review price variance, delivery mismatch, approval gap, and a related purchase.
- **Review & Repair Lab:** examine four reviewer lenses, add illustrative evidence, and run a deterministic re-review.
- **Second-Look Review:** compare competing explanations for the related transactions and identify the next evidence to request.
- Case review, policies, controls, recommended actions, reports, and an audit trail are included.

The case data and findings are illustrative. The prototype does not connect to a live procurement system or execute payments.

## Publish with GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`. The static site is published from the repository root. GitHub Pages sites are publicly accessible, including when the source repository is private.
